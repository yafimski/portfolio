# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest  | yes       |

## Reporting a vulnerability

Email security concerns to the repository owner via GitHub:
[https://github.com/yafimski/portfolio/security/advisories](https://github.com/yafimski/portfolio/security/advisories)

This is a static client-side portfolio site with no backend, authentication, or user data storage.
